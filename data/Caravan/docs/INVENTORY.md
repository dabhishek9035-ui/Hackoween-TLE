# Caravan v1.6 archive inventory

## Release and storage

- Official record: [Zenodo 15529786](https://zenodo.org/records/15529786).
- Archive size: 24,775,734,275 bytes; expected MD5: `ad3a7767db059f218380e9cce5f72452`.
- The archive checksum was verified before scanning. The scanner found 16,299 catchment NetCDF files across seven source folders.
- The authoritative per-catchment inventory is `data/Caravan/manifests/catchment_inventory.csv`; exact missingness summaries are in `reports/missingness_by_catchment.csv`.
- `data/Caravan/manifests/full_inventory_verbose.txt` is an older listing and does not describe this release completely.
- The compressed archive is downloaded under `data/Caravan/`; use the streaming reader instead of extracting a second full copy.

## Archive structure

- `Caravan-nc/timeseries/netcdf/<source>/<source>_<gauge_id>.nc`: daily time series per catchment.
- `Caravan-nc/attributes/<source>/`: climate, HydroATLAS, and source-specific tables.
- `Caravan-nc/licenses/`: source license and attribution notes.

The files use NetCDF3 and NetCDF4 formats. Decode dates from each file rather than assuming a shared UTC convention. Per-catchment row counts and timezone attributes are recorded in `catchment_inventory.csv`.
