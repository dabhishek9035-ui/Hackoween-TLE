# Reports

- `benchmark_metrics.json`: baseline and model scores for each 1-, 3-, and 5-day horizon, overall and by Caravan source.
- `per_catchment_metrics.csv`: persistence and model scores for each validation catchment and horizon.
- `missingness_by_catchment.csv`: streamflow and forcing coverage after the full archive is verified.
- `attribute_tables_inventory.csv`: schemas for extracted Caravan attribute tables.
- `preliminary_partial_archive/`: results retained from runs made before the full archive was available.
- `archive_diagnostics/`: earlier partial-download inventory diagnostics.
