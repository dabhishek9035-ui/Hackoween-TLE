# Preserved one-day preliminary run

These files preserve the earlier one-day-only run before the multi-horizon trainer was added. That run used a 7.95 GB archive prefix, 148 training catchments, 54 public-validation catchments, and 175,871 rows.

The current preliminary 1-, 3-, and 5-day results are in `../benchmark_metrics.json`; the root `train.py` is the maintained training entry point.
